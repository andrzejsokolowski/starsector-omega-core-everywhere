WHAT DOES THIS MOD DO?
- Omega cores drop from destroyed Omega ships again. No Astral Ascension needed.
- An Omega core in a colony building finally does something. Usually something absurd.


Production buildings make twice as much for half the demand, at double the upkeep: the facility can barely keep up with the core.
Every other building gets an Omega effect of its own, from doubled patrol fleets to stations that shrug off disruption.
Covers the base game, Industrial Evolution, AoTD Vaults of Knowledge and Terraforming & Station Construction. None of them is required.


The code is fully open source. You don't have to credit me. Claude Code built this anyway.
[color=red]Requires [b]LunaLib[/b].[/color]

[hr][center][size=12pt][b]Omega Core Drops[/b][/size][/center][hr]
[list]
[li]A destroyed Omega ship can drop the Omega core that commanded it, the same way Alpha, Beta and Gamma cores drop from AI ships.[/li]
[li]Bigger ships drop it more often: 33% for a frigate, 66% for a destroyer, 99% for a cruiser, always for a capital.[/li]
[li]The chance can be changed, or drops switched off, in LunaLib's settings.[/li]
[/list]
[hr][center][size=12pt][b]Omega Cores In Colony Buildings[/b][/size][/center][hr]
[list]
[li]Install an Omega core like any other AI core, on any building that takes one.[/li]
[li][b]Production buildings:[/b] production ×2, demand ×0.5, upkeep ×2.[/li]
[li][b]Everything else:[/b] an effect of its own, listed below. These keep the usual −25% upkeep of an AI core.[/li]
[li]The core picker and each building's tooltip show what the Omega core does, where the game would say "No effect".[/li]
[li]Buildings from other mods get the production effect if they make commodities.[/li]
[li]Only on your own colonies, and only while the building is working.[/li]
[/list]
[hr][center][size=12pt][b]Industrial Evolution Supercomputer Fix[/b][/size][/center][hr]
[list]
[li]An Omega core in IndEvo's Supercomputer used to crash the game a day later. Not any more.[/li]
[li]The fix stays on even with the building effects switched off.[/li]
[/list]
[hr][center][size=12pt][b]Settings[/b][/size][/center][hr]
[list]
[li]In LunaLib's settings menu ([b]Shift+F2[/b] in the campaign): Omega core drops on or off, the drop chance, and building effects on or off.[/li]
[/list]

[spoiler=FAQ]
[b]Does this mod make Omega cores drop without Astral Ascension?[/b]
Yes. That is half of what it is for. A destroyed Omega ship can drop its core: 33% for a frigate, up to always for a capital. The chance is in LunaLib's settings.
[b]And with Astral Ascension installed?[/b]
Astral Ascension keeps control of the drops and this mod's drop settings do nothing. The building effects work either way.
[b]The core picker still says "No effect" for the Omega core.[/b]
That is right for the buildings marked "No effect" above. Anywhere else, a Starsector update has probably changed the picker; the building's tooltip then shows the effect under an "Omega core" heading.
[b]Do I need Industrial Evolution, Vaults of Knowledge or TASC?[/b]
No. Their buildings only get Omega effects while that mod is installed. TASC is supported in its AoTD version.
[b]Do bonuses stack?[/b]
Yes, and they multiply. Commerce and a Resort Center on one colony give colony income ×4; Ground Defenses and a Harmonic Damper give ground defenses ×100.
[b]Can I add it to an existing save?[/b]
Yes.
[b]Can I remove it from a save?[/b]
Yes. The building effects come off before every save, so the save does not depend on this mod. Everything already handed out stays: delivered goods, officer levels, Hypercognition, restored ships and reputation.
[b]Why can the Maglev Central Hub not take an Omega core?[/b]
Vaults of Knowledge does not let any AI core into it, so there is nothing to put the Omega core into.
