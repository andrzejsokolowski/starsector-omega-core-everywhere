WHAT DOES THIS MOD DO?
- Omega cores drop from destroyed Omega ships again. No Astral Ascension needed.
- An Omega core in a colony building finally does something. Usually something absurd.
- An Omega core captaining one of your automated ships makes time run faster for it.
- Factions that buy AI cores pay 500 times the usual reputation for an Omega core.
- With Exotica Technologies or Special Hullmod Upgrades, an Omega core can go into a ship.


Production buildings make twice as much for half the demand, at double the upkeep.
Every other building gets an Omega effect of its own, from doubled patrol fleets to stations that shrug off disruption.
Covers the base game, Industrial Evolution, AoTD Vaults of Knowledge, AoTD Seats of Power and Terraforming & Station Construction. None of them is required.

[hr][center][size=12pt][b]Omega Core Drops[/b][/size][/center][hr]
[list]
[li]A destroyed Omega ship can drop the Omega core that commanded it, the same way Alpha, Beta and Gamma cores drop from AI ships.[/li]
[li]Bigger ships drop it more often: 33% for a frigate, 66% for a destroyer, 99% for a cruiser, always for a capital.[/li]
[li]The chance can be changed, or drops switched off, in LunaLib's settings.[/li]
[/list]
[hr][center][size=12pt][b]Omega Cores In Colony Buildings[/b][/size][/center][hr]
[list]
[li]Install an Omega core like any other AI core, on any building that takes one.[/li]
[li][b]Production buildings:[/b] production x2, demand x0.5, upkeep x2.[/li]
[li][b]Everything else:[/b] an effect of its own, listed below. These keep the usual -25% upkeep of an AI core.[/li]
[li]The core picker and each building's tooltip show what the Omega core does, where the game would say "No effect". A long effect is shortened in the picker; the building's tooltip shows it in full.[/li]
[li]Buildings from other mods get the production effect if they make commodities.[/li]
[li]Only on your own colonies, and only while the building is working.[/li]
[/list]
[hr][center][size=12pt][b]Omega Core Captains[/b][/size][/center][hr]
[list]
[li]The base game already lets an Omega core captain an automated ship. Your Omega core captains also get Omega Timeflow: time runs 25% faster for their ship.[/li]
[li]The bonus can be changed in LunaLib's settings. Enemy Omega ships do not get it.[/li]
[/list]
[hr][center][size=12pt][b]Turning In Omega Cores[/b][/size][/center][hr]
[list]
[li]Factions that buy AI cores take an Omega core for a 1,000,000 credit bounty (times the faction's rate) and 500 times the usual reputation. One core makes any of them your best friend.[/li]
[/list]
[hr][center][size=12pt][b]Exotica Technologies[/b][/size][/center][hr]
[list]
[li][b]Subsumed Omega Core:[/b] an automated ship takes in an Omega core for +150 bandwidth. Does not count towards the exotic limit.[/li]
[li][b]Omega Subcore:[/b] +150 bandwidth, weapons cost 2/4/8 OP less by size, fighters 4 and bombers 8 less.[/li]
[li]Both are installed with an Omega core. Computer fleets never have them.[/li]
[/list]
[hr][center][size=12pt][b]Special Hullmod Upgrades[/b][/size][/center][hr]
[list]
[li][b]Armament Support System (Omega):[/b] the Omega tier of the Alpha, Beta and Gamma core upgrades. Uses up an Omega core when installed.[/li]
[li]Autofire accuracy +100%, turret turn rate +100%, every weapon (missiles included) costs 3/5/8 OP less by size, deployment cost +25%.[/li]
[li]Learned together with the Alpha upgrade. Follows Special Hullmod Upgrades' settings for deployment cost, stacking core upgrades and losing the core with the ship.[/li]
[/list]
[hr][center][size=12pt][b]Industrial Evolution Supercomputer Fix[/b][/size][/center][hr]
[list]
[li]An Omega core in IndEvo's Supercomputer used to crash the game a day later. Not any more.[/li]
[li]The fix stays on even with the building effects switched off.[/li]
[/list]
[hr][center][size=12pt][b]Settings[/b][/size][/center][hr]
[list]
[li]In LunaLib's settings menu ([b]Shift+F2[/b] in the campaign): Omega core drops on or off, the drop chance, building effects on or off, and the Omega Timeflow bonus.[/li]
[/list]

[spoiler=FAQ]
[b]Does this mod make Omega cores drop without Astral Ascension?[/b]
Yes. That is half of what it is for. A destroyed Omega ship can drop its core: 33% for a frigate, up to always for a capital. The chance is in LunaLib's settings.
[b]And with Astral Ascension installed?[/b]
Astral Ascension keeps control of the drops and this mod's drop settings do nothing. The building effects work either way.
[b]And with Astral Ascension Renewed?[/b]
They work together: Astral Ascension Renewed adds the Omega core administrator and colonies past size 10, this mod covers the buildings. This mod's drop settings are used.
[b]The core picker still says "No effect" for the Omega core.[/b]
That is right for the buildings marked "No effect" above. Anywhere else, a Starsector update has probably changed the picker; the building's tooltip then shows the effect under an "Omega core" heading.
[b]Do I need Industrial Evolution, Vaults of Knowledge or TASC?[/b]
No. Their buildings only get Omega effects while that mod is installed. TASC is supported in its AoTD version.
[b]Do I need Exotica Technologies or Special Hullmod Upgrades?[/b]
No. Their Omega upgrades only exist while that mod is installed.
[b]Do bonuses stack?[/b]
Yes, and they multiply. Commerce and a Resort Center on one colony give colony income x4; Ground Defenses and a Harmonic Damper give ground defenses x100.
[b]Can I add it to an existing save?[/b]
Yes.
[b]Can I remove it from a save?[/b]
Yes, once the Omega Subcore, Subsumed Omega Core and Armament Support System (Omega) are off your ships. The building effects and Omega Timeflow come off before every save, so the save does not depend on them. Everything already handed out stays: delivered goods, officer levels, Hypercognition, restored ships and reputation.
[b]Why can the Maglev Central Hub not take an Omega core?[/b]
Vaults of Knowledge does not let any AI core into it, so there is nothing to put the Omega core into.
